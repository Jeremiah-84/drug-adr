약 이상반응 찾기 (시험판)

환자에게 새로 생긴 문제(신기능 저하, 간수치 상승, 새 증상)가 복용 중인 약 때문일 수 있는지 식약처 허가 첨부문서 기준으로 빠르게 찾아보는 도구입니다. AI 없이 첨부문서 문장을 규칙으로 정리했습니다.

1. 내려받기

확장 프로그램 내려받기 (약 3MB)

받은 파일을 마우스 오른쪽 → 압축 풀기(모두 압축 풀기) 하세요. drug-adr-extension 폴더가 생깁니다. 이 폴더는 지우지 말고 그대로 두세요(지우면 확장 프로그램도 사라집니다).

2. 설치 (Chrome)

  1. 주소창에 chrome://extensions 를 입력합니다.
  2. 오른쪽 위 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램 로드를 누르고 위의 drug-adr-extension 폴더를 선택합니다.
  4. 주소창 오른쪽 퍼즐 모양 아이콘 → "약 이상반응 찾기" 옆 핀을 눌러 고정하면 편합니다.

Edge는 edge://extensions 에서 왼쪽 아래 "개발자 모드"를 켠 뒤 같은 방법으로 설치합니다. 네이버 웨일 등 다른 브라우저는 아직 시험하지 않았습니다.

3. 사용법

  1. 처방 화면을 띄운 상태에서 확장 프로그램 아이콘(또는 Alt+Shift+Y)을 누르면 오른쪽에 패널이 열립니다.
  2. 지금 보고 있는 화면에서 약 찾기를 누르면 처방 화면의 약 이름을 읽어 자동으로 추가합니다. 처음 한 번은 그 사이트를 읽어도 되는지 허용을 묻습니다.
  3. 화면을 읽지 못하면 약 이름(제품명 일부도 가능)을 직접 입력하거나, 처방 목록을 붙여넣으세요. 화면에서 글자를 드래그한 뒤 오른쪽 클릭 → "약 이상반응 찾기에 추가"도 됩니다.
  4. 새로 생긴 문제에 "egfr", "간수치", "어지럼", "부종"처럼 자유롭게 쓰면 원인 가능성이 있는 약이 높음 · 가능성 있음 · 낮음 · 매우 드묾 순으로 나옵니다. 근거 문장과 식약처 원문 링크를 꼭 확인하세요.
  5. 아래 신기능·간기능이 떨어졌을 때에서 약별 금기·용량 조절·주의 여부를 볼 수 있습니다.
  6. 다음 환자로 넘어갈 때는 새 환자 (모두 지우기)를 누르세요.

휴대폰이나 설치형 EMR에서는 웹 버전을 쓰세요: jeremiah-84.github.io/drug-adr (화면 읽기 기능만 빼고 같습니다). Chrome·Edge에서 주소창의 "앱 설치" 아이콘을 누르면 작은 창으로 따로 띄워 처방 창 옆에 둘 수 있습니다.

4. 개인정보와 시험 기간 통계

처방 화면 내용과 환자 정보는 이 컴퓨터 밖으로 나가지 않습니다. 시험 기간에는 동의하신 경우에만 익명 사용 통계(기능 사용 종류, 추가한 성분, 고른 문제 항목, 개수, 시험 광고 노출·클릭)를 보내며, 패널 맨 아래에서 언제든 끌 수 있습니다. 자세한 내용은 개인정보처리방침을 보세요.

5. 알아두실 점

  • 약마다 대표 제품 1개의 첨부문서를 기준으로 하며, 규칙에 따라 자동 추출해 누락이나 오분류가 있을 수 있습니다. 진료 판단의 참고로만 쓰세요.
  • 약 데이터는 매월 자동으로 새로 받아집니다. 프로그램 자체가 바뀌면 새 파일을 다시 안내드립니다.
  • 패널 아래의 광고는 시험용 배너입니다. 거슬리는지, 위치가 괜찮은지 의견 주시면 큰 도움이 됩니다.
