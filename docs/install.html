메디스캔 프로 설치 안내

환자에게 새로 생긴 문제가 복용 중인 약 때문일 수 있는지, 식약처 허가 첨부문서 기준으로 빠르게 찾아보는 도구입니다. 그림을 따라 5분이면 설치할 수 있어요.

⬇ 확장 프로그램 내려받기약 3MB · Chrome, Edge
1

내려받기 버튼을 누르세요

아래 초록 버튼을 누르면 drug-adr-extension.zip 파일이 다운로드 폴더에 저장됩니다.

2

압축을 푸세요

다운로드 폴더에서 zip 파일을 마우스 오른쪽 버튼으로 누르고 모두 압축 풀기 → 압축 풀기를 누르세요. 같은 이름의 노란 폴더가 생깁니다.

3

확장 프로그램 관리 화면을 여세요

Chrome 주소창에 chrome://extensions 를 그대로 입력하고 Enter를 누르세요. (Edge는 edge://extensions)

4

개발자 모드를 켜세요

화면 오른쪽 위의 개발자 모드 스위치를 눌러 켜세요. 스위치가 파랗게 바뀌면 됩니다. (Edge는 왼쪽 아래에 있습니다)

5

압축 푼 폴더를 선택하세요

새로 생긴 압축해제된 확장 프로그램 로드 버튼을 누르고, 2번에서 생긴 drug-adr-extension 폴더를 한 번 클릭한 뒤 폴더 선택을 누르세요.

6

아이콘을 고정하세요

주소창 오른쪽의 퍼즐 모양을 누르고, 메디스캔 프로 옆의 핀을 누르세요. 이제 초록 아이콘이 항상 보입니다.

7

처방 화면에서 약을 읽어 오세요

처방 화면을 띄운 채 초록 아이콘을 누르면 오른쪽에 패널이 열립니다. 지금 보고 있는 화면에서 약 찾기를 누르고, 처음 한 번 나오는 허용 창에서 허용을 누르세요.

8

새로 생긴 문제를 쓰세요

새로 생긴 문제 칸에 "egfr", "간수치", "어지럼"처럼 편하게 쓰면 원인 가능성이 있는 약이 높음 → 매우 드묾 순서로 나옵니다. 근거 문장 보기로 첨부문서 원문을 꼭 확인하세요.

설치형 EMR이나 휴대폰에서는? 화면 읽기만 빼고 똑같은 웹 버전을 쓰세요. Chrome·Edge 주소창 오른쪽의 "앱 설치" 아이콘을 누르면 작은 창으로 따로 띄워 처방 창 옆에 둘 수 있고, 휴대폰은 "홈 화면에 추가"를 누르면 됩니다.
잘 안 될 때
· 압축 푼 drug-adr-extension 폴더는 지우지 마세요. 지우면 확장 프로그램도 사라집니다.
· "화면에서 약을 찾지 못했습니다"가 나오면 약 이름 일부를 직접 입력하거나, 처방 목록을 붙여넣어도 됩니다.
· 매월 약 데이터는 자동으로 새로 받아집니다. 프로그램이 바뀌면 새 파일을 다시 안내드립니다.
