약 이상반응 찾기 개인정보처리방침

시행일: 2026-11-16 (초안)

수집하는 정보

이 프로그램은 이름, 연락처, 환자 정보 등 개인정보를 수집하지 않습니다.

익명 사용 통계 (시험 기간)

사용자가 동의한 경우에 한해, 도구 개선을 위해 다음 정보를 Google 애널리틱스로 보냅니다: 설치마다 무작위로 만든 번호, 사용 시각, 기능 사용 종류(검색·화면 읽기·붙여넣기 등), 추가한 약의 성분 이름, 고른 문제 항목(정해진 목록 중 하나), 찾은 약의 개수, 광고 노출·클릭 여부.

화면에서 읽은 글자, 직접 입력한 문장, 환자 정보는 보내지 않습니다. 첫 화면 또는 화면 아래 "끄기"로 언제든 통계를 끌 수 있습니다.

화면 읽기 기능

"지금 보고 있는 화면에서 약 찾기"를 누르면, 사용자가 허용한 사이트의 현재 화면 글자를 사용자 컴퓨터 안에서만 읽어 약 이름을 찾습니다. 읽은 내용은 저장하거나 외부로 전송하지 않습니다.

기기에 저장하는 정보

마지막으로 입력한 약 목록과 화면 설정은 사용자 브라우저 안에만 저장되며 "새 환자" 버튼으로 지울 수 있습니다.

데이터 업데이트와 광고

약 데이터 갱신을 위해 공개된 데이터 파일을 내려받습니다. 광고 영역은 별도 주소의 페이지로 분리되어 있어 처방 화면이나 입력한 약 정보에 접근할 수 없습니다. 광고 제공자가 쿠키를 사용할 수 있으며, 이 경우 해당 제공자의 방침이 적용됩니다.
